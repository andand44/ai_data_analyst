# AI Data Analyst (Text-to-SQL)

Интерактивный веб-сервис на базе LLM для анализа табличных данных (CSV) с помощью естественного языка. Проект демонстрирует передовой подход к построению AI-агентов с использованием строгой типизации (PydanticAI) и управлением состоянием (SQLite).

`![Демонстрация работы AI Data Analyst](./assets/demo.png)`

## 🚀 Возможности
- **Text-to-SQL**: Загрузите любой CSV-файл, задайте вопрос на русском языке, и агент сам напишет SQL-запрос, выполнит его и вернет красивый отчет.
- **Умный роутинг моделей (Fallback)**: При старте бот динамически получает список доступных бесплатных LLM-моделей через OrcaRouter. Если одна модель выдает ошибку (лимит 429 или 404), агент мгновенно переключается на следующую.
- **Локальный Fallback**: Если все облачные API недоступны, система бесшовно переключается на локальную модель `qwen2.5:1.5b` через Ollama, гарантируя 100% отказоустойчивость.
- **История чатов (SQLite)**: Все сессии и сообщения сохраняются в локальной базе данных SQLite. Вы можете переключаться между чатами, удалять их и возвращаться к старым документам, как в ChatGPT.
- **Безопасность**: Встроенная защита от SQL-инъекций. Агент имеет право выполнять только запросы на чтение (`SELECT`), любые попытки изменения данных (`DROP`, `DELETE`, `UPDATE`) блокируются.
- **In-Memory аналитика**: Запросы выполняются в сверхбыстрой аналитической базе DuckDB, которая создается в оперативной памяти на лету.

## 🧰 Стек технологий
- **PydanticAI**: Фреймворк для создания надежных агентов со строгими типами данных.
- **DuckDB**: Векторизованная in-memory база данных для аналитики.
- **SQLite**: Легковесная база данных для хранения истории чатов.
- **Streamlit**: Веб-интерфейс для быстрого прототипирования.
- **Pandas & Tabulate**: Обработка и форматирование табличных данных.
- **OrcaRouter (OpenAI API)**: Пул LLM-моделей.

## 🏃‍♂️ Запуск
1. Клонируйте репозиторий.
2. Установите зависимости: 
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` с вашим ключом: 
    ```bash
    ORCA_API_KEY=ваш_ключ
    ```
4. Запустите приложение: 
    ```bash
    streamlit run app.py
    ```
